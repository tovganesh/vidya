## Reporting a Vulnerability

The Vidya team takes the security of school and student data extremely seriously. If you discover a vulnerability, **do NOT open a public GitHub issue**.

Please report vulnerabilities privately via email to:
**security@vidya.org**

### What to Include:
- Description of the vulnerability.
- Step-by-step reproduction steps or proof-of-concept.
- Affected components or endpoints.
- Potential impact on tenant isolation or student privacy.

We will acknowledge receipt within 48 hours and provide regular progress updates on remediation.
